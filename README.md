♟️ Juno Chess

Welcome to Juno Chess!

This is a chess game that I built as a personal project to learn, experiment, and improve my skills in building applications. The goal is to keep developing the game and hopefully turn it into a more complete and polished chess application.

The project is still a work in progress, so I know there are things that can be improved. I plan to continue adding improvements, fixing bugs, and making the overall experience better over time.

🎮 About the Game

Juno Chess is an offline chess game that can be played without an internet connection.

I'm building this project step by step, and I want to continue improving it based on testing, feedback, and new ideas.

Some things I would like to improve in the future include:

Better overall user interface

More polished chess gameplay

Bug fixes and performance improvements

Better mobile experience

Additional chess features

Better support for different devices

Preparing the game for public release

📥 How to Download
Option 1: Download from GitHub

Go to the project repository:

https://github.com/junodev1/CHESS-GAME

Click the green Code button.

Click Download ZIP.

Extract the ZIP file somewhere on your computer.

Open the extracted CHESS-GAME folder.

Option 2: Clone with Git

If you have Git installed, open your terminal and run:

git clone https://github.com/junodev1/CHESS-GAME.git


Then enter the project folder:

cd CHESS-GAME


Install the required dependencies:

npm install

💻 Running the Project

After downloading the project and installing the dependencies, you can start working with the files in the project.

Install dependencies:

npm install


The main web application files are located inside the www folder.

If you are working with the Capacitor version of the project, you can synchronize the project with:

npx cap sync

📱 Android

This project also uses Capacitor, which allows the web application to be packaged as a native Android application.

If you have Android Studio and the Android SDK installed, you can open the Android project with:

npx cap open android


From there, you can build and test the application on an Android device or emulator.
